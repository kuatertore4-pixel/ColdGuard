Подключение физического оборудования

ColdGuard спроектирован для работы с микроконтроллером Arduino Uno R3 и прецизионным цифровым датчиком температуры Dallas DS18B20.

Статус: Физический датчик не подключен
В настоящее время активен демонстрационный генератор телеметрии. Для перехода на реальные измерения выполните шаги ниже.
1
Физическое подключение датчика DS18B20

Подключите датчик DS18B20 к плате Arduino Uno по схеме 1-Wire с подтягивающим резистором 4.7 кОм:

  • Красный провод (VCC): к выводу 5V на Arduino
  • Черный провод (GND): к выводу GND на Arduino
  • Желтый/синий провод (DATA): к цифровому пину D2 на Arduino
  • Резистор 4.7 кОм: между линиями 5V и DATA
2
Прошивка Arduino (Скетч для передачи JSON в COM-порт)

Загрузите в плату скетч через Arduino IDE. Он считывает температуру и отправляет структурированные пакеты:

void loop() {
  sensors.requestTemperatures();
  float tempC = sensors.getTempCByIndex(0);
  // Передача JSON в Serial (Baud: 9600)
  Serial.print("{\"temp\": ");
  Serial.print(tempC, 2);
  Serial.println(", \"device\": 1}");
  delay(5000);
}
3
Локальный мост (Serial → WebSocket)

Для непрерывного мониторинга 24/7 запустите локальный мост ColdGuard, который считывает показания из COM-порта и транслирует их веб-интерфейсу через локальный WebSocket (ws://127.0.0.1:8765):

python bridge/serial_bridge.py
# Или для тестирования без датчика:
python bridge/serial_bridge.py --demo
Важно об интеграции: Основным и рекомендованным промышленным способом подключения является Python-мост. Браузерный Web Serial API захватывает COM-порт эксклюзивно и заблокирует работу фонового моста.
